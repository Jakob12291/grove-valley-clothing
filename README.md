# Grove Valley Clothing

A Discord-inspired clothing storefront built with TypeScript and Vite.

## Add the dancing gorilla logo

Place your GIF at:

`public/gorilla-dance.gif`

The animated `GV` fallback is shown until that file is added. Only upload media you have permission to use.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
