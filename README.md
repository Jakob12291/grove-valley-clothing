# Grove Valley Clothing

A Discord-inspired clothing storefront built with TypeScript and Vite.

## Add the dancing gorilla logo

The supplied dancing gorilla clip is stored at:

`public/gorilla-dance.mp4`

The animated `GV` fallback is shown if that file cannot load. Only use media you have permission to publish.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
